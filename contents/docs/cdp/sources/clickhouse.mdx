The ClickHouse connector can link your database tables to PostHog. It uses Arrow streaming to handle large databases without buffering the entire dataset in memory, making it suitable for multi-terabyte deployments.

To link ClickHouse:

1. Go to the [Data pipeline page](https://app.posthog.com/data-management/sources) and the sources tab in PostHog
2. Click **New source** and select ClickHouse
3. Enter your database connection details:
    - **Host** - The hostname or IP of your ClickHouse server like `clickhouse.example.com` or `123.132.1.100`.
    - **Port** - The port your ClickHouse server is listening on. The default is `8443` for HTTPS or `8123` for HTTP.
    - **Database** - The name of the database you want like `analytics_db`.
    - **User** - The username with the necessary permissions to access the database.
    - **Password** - The password for the user (optional for some configurations).
    - **Use HTTPS** - Whether to use HTTPS for the connection. Enabled by default.
    - **Verify SSL** - Whether to verify the server's SSL certificate. Enabled by default.
4. If you need to connect through an SSH tunnel, enable and configure it (optional):
    - **Tunnel host** - The hostname of your SSH server.
    - **Tunnel port** - The port your SSH server is listening on.
    - **Authentication type:**
        - For password authentication, enter your SSH username and password.
        - For key-based authentication, enter your SSH username, private key, and optional passphrase.
5. Click **Next**

The data warehouse then starts syncing your ClickHouse data. You can see details and progress in the [sources tab](https://app.posthog.com/data-management/sources).

> **Permissions:** The ClickHouse source only requires read permissions on the schemas and tables you intend to sync.

## Incremental sync support

The ClickHouse connector supports [incremental sync](/docs/cdp/sources#incremental) for efficient data loading. Supported cursor field types:

- Integer types (`Int8` through `Int256`, `UInt8` through `UInt256`)
- Date types (`Date`, `Date32`)
- DateTime types (`DateTime`, `DateTime64`)

## Skipped tables

Some ClickHouse table types can't provide row counts without expensive full scans. These tables show as "Skipped" in the table list:

- Views
- Memory tables
- Buffer tables
- Log tables
- Kafka tables
- URL tables

MergeTree tables, Distributed tables, and MaterializedViews with a target table sync normally.
